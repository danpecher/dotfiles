# macOS and portable Linux Sway setup

This repository is the desired state for a useful, bounded workstation. It
supports macOS plus Fedora, Debian, Ubuntu, and Arch-family Linux with Sway,
combining chezmoi, native package managers, mise, and explicit scripts.

`master` is the single source of truth. The normal personal setup is the
default; `Brewfile.minimal` is an optional lightweight profile, not a branch.

## Canonical checkout

The canonical source directory is:

```text
~/Code/dotfiles
```

Chezmoi's generated configuration records that path as `sourceDir`. Do not keep
a second editable clone under `~/.local/share/chezmoi`; two source clones make it
unclear which repository controls the live files.

## Daily workflow

```bash
cd ~/Code/dotfiles

make snapshot  # record what is installed now
make diff      # browse repo-versus-live file drift with Delta
make plan      # compatibility alias for make diff
make apply     # reconcile chezmoi-managed files only
make packages  # install declared packages, runtimes, and plugins
make services  # enable/start declared background services
make doctor    # fail if declared and observed state differ
make validate  # validate scripts, JSON, templates, Kanata, and Brewfiles
make lint      # run ShellCheck on managed shell scripts
make format    # apply the repository's shell formatting style
make watch     # continuously rerun validation while editing
```

Inside LazyGit, `Ctrl+X` opens the same interactive chezmoi diff and returns to
LazyGit when the pager exits. Use `n` and `N` to move between changed files.

Homebrew cleanup is deliberately separate and preview-only:

```bash
make cleanup-preview
```

Review the output and remove individual packages yourself. No repository script
runs `brew bundle cleanup --force`.

Version pinning and rolling-package rules are documented in
[`docs/update-policy.md`](docs/update-policy.md).

## Desired state versus observed state

Desired state is maintained intentionally:

- Chezmoi source files: shell, Git, SSH, Ghostty, Kanata, Neovim,
  mise, VS Code, Hammerspoon, tmux, btop, LazyGit, Mole,
  GH CLI, Testcontainers, personal scripts, and global gitignore
- `Brewfile`: personal machine-wide formulae, applications, fonts, Mac App
  Store entries, and VS Code extensions
- `Brewfile.minimal`: optional lightweight machine/VM package set
- `packages/*-common.txt`: native package baselines for each Linux distribution
- `packages/*-sway.txt`: native Sway desktop package baselines
- `scripts/03_macos-defaults.sh`: explicitly managed macOS preferences

Private observed state is generated by `make snapshot` under
`state/observed/<hostname>`. It inventories the active OS package manager,
applications or services, VS Code, and mise. These files are git-ignored local
diagnostics and are never automatically copied into a declaration.

## Fresh installation

Run interactively on macOS, Fedora, Debian, Ubuntu, or Arch:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/danpecher/dotfiles/master/scripts/01_bootstrap.sh)"
```

The entry script detects the OS and Linux distribution family, installs prerequisites,
clones `master` to `~/Code/dotfiles`, initializes chezmoi from that checkout,
shows the complete destination diff, and asks before applying. It then
provisions native packages, portable mise tools, and systemd services.
Bootstrap steps can be omitted with a comma-separated `SKIP_STEPS` list. The
supported steps are `github` (SSH-key creation, authentication, key upload, and
SSH transport) and `kanata` (installation, service setup, and service audit).
For an ARM64 VM, skip both while retaining the full Sway desktop profile:

```bash
SKIP_STEPS=github,kanata /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/danpecher/dotfiles/master/scripts/01_bootstrap.sh)"
```

With `github` skipped, the public dotfiles repository is cloned over HTTPS and
the generated Git config does not rewrite GitHub HTTPS URLs to SSH. To skip
only interactive GitHub setup, use `SKIP_STEPS=github`.

Use the optional minimal profile with:

```bash
PROFILE=minimal /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/danpecher/dotfiles/master/scripts/01_bootstrap.sh)"
```

On the same physical Mac, only the personal/admin account should manage the
shared `/opt/homebrew` installation. A second account can share the repository's
dotfiles while using account-local mise and editor state; it should not run
Homebrew cleanup against the minimal Brewfile.

All supported Linux distributions include the portable CLI/editor baseline and an enabled
Tailscale daemon; Tailscale account authentication remains an explicit manual
step. The personal profile additionally includes Sway, Waybar, Foot, Rofi,
Dunst, Kanshi, Wayland screenshot/clipboard tools, VS Code from Microsoft's
official repositories on Fedora/Debian/Ubuntu, Code OSS on Arch, and Kanata as
a system service. The minimal profile omits the desktop. See
[`docs/linux-sway.md`](docs/linux-sway.md) for the support matrix, keybindings,
monitor setup, and service diagnostics.

Pass the same `SKIP_STEPS` value to later package, service, and doctor commands
when you want those omissions to remain intentional. `SKIP_KANATA=1` remains a
backward-compatible alias for `SKIP_STEPS=kanata`.

## Adding changes

Capture an intentional live-file change with chezmoi, then review it:

```bash
chezmoi re-add ~/.zshrc
make diff
git diff
```

For software, edit the appropriate Brewfile, Linux package manifest, or the
Linux-only section of the mise configuration.
Use `make snapshot` to see undeclared experiments without automatically
adopting them.

## Boundaries

Privacy permissions, Apple ID state, application logins, licenses, SSH private
keys, MDM enrollment, and application databases cannot be safely reproduced by
this repository. See `docs/manual-steps.md`.
